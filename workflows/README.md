状态：**NOT_RUN**。这两条工作流只能在真实 consumer Muse + 真实 Windows 交互会话上执行；本文件只定义步骤、核验方法与证据格式，不代表任何一次执行。

## 通用规则

- 每条工作流连续执行 10 次，每次随机化文件名与内容。
- 每次记录：动作数、授权次数、成功率、耗时、人工介入。任一次失败都定位原因并回归；不删失败轮次、只展示最好的一次。
- 测试目录：授权根下的 `bridge-e2e/<workflow>/<run-####>/`，每次运行新建，跑完保留证据、不自动删除。
- 核验一律用文件读回 + SHA-256，不用“屏幕上看起来对了”代替。
- 降级规则（实施包 T23）：若文件 API 通过、视觉不通过，交付范围如实降为文件桥；若 UIA 可读但无法可靠输入，交付范围为只读观察。功能降级是有效交付，伪装完成不是。
